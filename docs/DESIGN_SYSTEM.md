# Design System

## Brand Colours

- Primary Blue: #2563EB
- Success Green: #10B981
- Warning: #F59E0B
- Danger: #EF4444
- Background: #F8FAFC
- Surface: #FFFFFF
- Primary Text: #111827
- Secondary Text: #6B7280
- Border: #E5E7EB

## Typography

- Font Family: Inter, Arial, sans-serif
- Heading Scale: Use clear hierarchy with strong emphasis
- Body Text: Readable and concise

## Spacing System

Use increments of 8px:
- 8px
- 16px
- 24px
- 32px
- 48px
- 64px

## Border Radius

- 10px
- 12px
- 16px
- 20px

## Buttons

Use primary, secondary, and danger variants with consistent spacing and hover states.

## Cards

Cards should provide subtle elevation, rounded corners, and structured layout.

## Inputs

Inputs should include labels, focus states, helper text, and error messaging guidance.

## Icons

Use simple, modern line icons that align with the fintech theme.

## Responsive Breakpoints

- Mobile: 320px to 767px
- Tablet: 768px to 1023px
- Desktop: 1024px and above

## Animation Guidelines

- Keep transitions short and purposeful
- Use subtle motion for hover and focus states
- Avoid distracting or over-animated interactions
