# Contributing Guide

## Branch Naming

Use descriptive branch names such as:
- feature/dashboard-layout
- feature/otp-flow
- bugfix/spacing-issue
- chore/update-docs

## Commit Message Conventions

Prefer concise, descriptive commit messages:
- feat: add dashboard summary view
- fix: correct mobile spacing issue
- docs: update architecture notes
- chore: scaffold shared styles

## Pull Requests

Each pull request should include:
- A clear summary
- Related issue or task reference
- Screenshots when UI changes are involved
- Notes on testing or validation

## Code Reviews

- Keep review comments specific and constructive
- Prefer explanation over blame
- Confirm that documentation remains aligned with implementation

## Folder Ownership

- Pages and layout: frontend contributors
- Styling: UI and design contributors
- JavaScript logic: feature owners
- Documentation: product and engineering leads
