# Team Guidelines

## Professional Communication

Keep discussions clear, respectful, and focused on outcomes. Use concise updates and meaningful context.

## Daily Updates

Share progress, blockers, and next steps in a short and consistent format.

## Code Quality Expectations

- Follow existing naming conventions
- Keep components and modules focused
- Avoid unnecessary complexity
- Add comments where logic is not obvious

## Documentation

Documentation should stay current. Update docs when the product flow or architecture changes.

## Testing

Test changes manually in the browser and verify responsiveness across key breakpoints.

## Respect

Be considerate of design decisions, technical constraints, and team capacity.

## Collaboration

Work collaboratively across product, design, and engineering to keep the experience aligned.
