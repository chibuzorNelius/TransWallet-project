# User Flow

## Registration

A new user lands on the registration page, enters account details, and submits the form. The experience simulates account creation and routes to the OTP verification step.

## Login

A returning user enters an email and password. The app validates simulated credentials and redirects them to the dashboard if the account exists.

## OTP

After registration or login, the user is directed to an OTP screen. The flow simulates a verification code and allows the user to continue after validation.

## Dashboard

The dashboard presents account summary, quick actions, upcoming activity, and wallet highlights.

## Wallet

The wallet view shows balances and allows the user to navigate to transfer or exchange actions.

## Send Money

The transfer experience allows a user to enter a recipient and amount and submit a simulated money transfer.

## Receive Money

The receive section provides a simulated payment request view with shareable details.

## Exchange

The exchange flow presents currency conversion options and a mock exchange summary.

## Transaction History

The transaction history page lists recent transfers, exchanges, and crypto actions.

## Crypto Request

A user can submit a crypto purchase request with amount, coin preference, and notes.

## Logout

The logout flow clears the simulated session and returns the user to the landing page or login experience.
